# BrewSpot Web

기존 `ios/` 앱 버전은 그대로 두고, 이 폴더에서 웹 버전을 별도로 개발합니다.

## 시작하기

1. `cp .env.example .env.local`
2. `.env.local`에 Supabase 값을 입력
3. `npm install`
4. `npm run dev`

Supabase 환경 변수가 없으면 앱은 자동으로 데모 데이터 모드로 실행됩니다.

## 이번 1차 웹 범위

1. 이메일 로그인 / 회원가입
2. 카페 목록, 검색, 카테고리 필터
3. 카페 상세
4. 리뷰 조회 / 작성
5. 북마크
6. 마이페이지 요약

`커뮤니티`, `랭킹`, `홈바리스타`는 다음 단계에서 확장할 수 있도록 구조만 열어둡니다.
